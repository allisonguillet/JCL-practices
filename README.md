# Mainframe JCL & Utilities Portfolio

Welcome to my Mainframe hands-on repository. This project serves as a structured collection of **JCL (Job Control Language)** scripts and batch automation workflows developed on z/OS.

The goal of this repository is to document practical implementations of batch data processing, multi-step pipelines, and dataset management following Mainframe industry standards.

---

## 🛠️ Mainframe Environment & Tools
- **Operating System:** IBM z/OS
- **Primary Utilities:** DFSORT, IDCAMS, IEFBR14, IEBGENER
- **Development & Operations:** IBM Zowe Explorer (VS Code extension), ISPF/TSO, SDSF
- **Version Control:** Git & GitHub
